개인정보처리방침

시행일: 2026-10-26

Classic Film Uploader(이하 "앱")는 운영자 본인의 유튜브 채널에 영상을 업로드하는 개인용 도구입니다.

1. 앱이 접근하는 Google 사용자 데이터

  • 운영자가 Google 로그인 동의 화면에서 허용한 범위(YouTube 영상 업로드 권한)로만 접근합니다.
  • 앱은 운영자의 채널에 영상을 업로드하고 영상 정보(제목, 설명, 공개 상태, 예약 시간)를 설정하는 데에만 이 권한을 사용합니다.

2. 수집·저장

  • 앱은 운영자 외 다른 사용자의 개인정보를 수집하지 않습니다.
  • 로그인 후 발급되는 인증 토큰은 운영자가 관리하는 서버에만 저장되며, 파일 접근 권한으로 보호됩니다.
  • Google 사용자 데이터를 별도 데이터베이스에 보관하거나 분석에 사용하지 않습니다.

3. 공유·제3자 제공

앱은 Google 사용자 데이터를 제3자에게 판매, 공유, 이전하지 않습니다. 광고 목적으로 사용하지 않습니다.

4. Google API 서비스 사용자 데이터 정책

앱의 Google API 정보 사용 및 다른 앱으로의 전달은 제한된 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다. 앱은 YouTube API Services를 사용하며 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

5. 접근 권한 철회와 삭제

  • 운영자는 언제든지 Google 계정 권한 설정에서 앱의 접근을 철회할 수 있습니다.
  • 철회 후 서버에 저장된 인증 토큰을 삭제하면 앱은 더 이상 채널에 접근할 수 없습니다.
