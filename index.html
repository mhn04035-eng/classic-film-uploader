Classic Film Uploader

Classic Film Uploader는 운영자 본인이 소유한 유튜브 채널에 쇼츠 영상을 업로드하고 공개 예약을 설정하는 개인용 자동화 도구입니다.

무엇을 하나요

  • 운영자가 만든 영상 파일을 운영자의 유튜브 채널에 업로드합니다.
  • 영상의 제목, 설명, 공개 상태, 공개 예약 시간을 설정합니다.

누가 쓰나요

이 도구는 운영자 한 명이 자신의 채널에만 사용합니다. 일반 사용자에게 제공하지 않으며, 다른 사람의 계정이나 데이터에 접근하지 않습니다.

YouTube API 서비스 사용

이 앱은 YouTube API Services를 사용합니다. 사용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.
